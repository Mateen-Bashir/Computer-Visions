# Machine Learning Case Studies Collection

## Overview
This project contains multiple real-world machine learning case studies implemented using Python and Scikit-learn. The project demonstrates the practical application of:

- Cluster Analysis
- Principal Component Analysis (PCA)
- Artificial Neural Networks (ANN)

The case studies are based on industries such as healthcare, finance, retail, aviation, and manufacturing.

---

# Technologies Used

- Python
- Scikit-learn
- Pandas
- Matplotlib
- NumPy

---

# Case Studies

## 1. Dynamic Pricing Optimization in Airline Industry
### Technique
Cluster Analysis (K-Means)

### Objective
Identify hidden passenger segments using customer behavior data to improve dynamic ticket pricing strategies.

### Features
- Passenger segmentation
- Customer behavior analysis
- Cluster visualization

---

## 2. Early Diagnosis of Parkinson’s Disease
### Technique
PCA + Artificial Neural Networks

### Objective
Reduce high-dimensional voice feature data and classify Parkinson’s disease cases accurately.

### Features
- Dimensionality reduction using PCA
- ANN-based classification
- Medical data analysis

---

## 3. Credit Card Fraud Detection at Scale
### Technique
ANN + PCA

### Objective
Detect fraudulent credit card transactions from large-scale financial datasets.

### Features
- Fraud classification
- Noise reduction using PCA
- Neural network prediction

---

## 4. Consumer Trend Mapping in Retail Chain
### Technique
Cluster Analysis + PCA

### Objective
Analyze regional customer behavior and identify shopping trends.

### Features
- Retail customer segmentation
- PCA visualization
- Behavioral clustering

---

## 5. Quality Control in Smart Manufacturing
### Technique
Artificial Neural Networks

### Objective
Detect defective products using real-time industrial sensor data.

### Features
- Product defect classification
- Automated quality assurance
- Sensor-based prediction
