# Gabor Filter-Based Texture Analysis Lab

## Overview
This lab demonstrates the use of Gabor filters for texture-based feature extraction in computer vision tasks.

## Tasks Covered
1. Surface Defect Detection  
2. Architectural Texture Analysis  
3. Fingerprint Ridge Enhancement  
4. Texture Classification using SVM  
5. Facial Expression Recognition  
6. Satellite Image Segmentation  
7. Architectural Material Recognition  

## Methodology
- Convert image to grayscale
- Apply Gabor filters at multiple orientations
- Extract statistical features (mean, variance)
- Use features for classification or analysis

## Tools Used
- OpenCV
- NumPy
- Matplotlib
- Scikit-learn

## Results
- Texture patterns successfully enhanced
- Orientation-based features extracted
- Classification performed using SVM
- Different textures (brick, forest, fingerprint ridges) clearly distinguished

## Conclusion
Gabor filters are effective for extracting orientation and frequency-based texture features and can be used in various real-world applications.
