# Object Detection Lab Using YOLOv8

## Overview
This lab demonstrates multiple real-world applications of object detection using YOLOv8. The system performs image-based detection for different case studies including smart classroom, parking, wildlife monitoring, industrial defects, and retail analytics.

## Technology Used
- YOLOv8 (Ultralytics)
- OpenCV
- Matplotlib
- Python

## Case Studies

### 1. Smart Classroom Monitoring
Detects human presence for attendance automation.

### 2. Smart Parking System
Detects vehicles like cars, bikes, and trucks.

### 3. Wildlife Monitoring
Identifies animals in natural environments.

### 4. Industrial Defect Detection
Detects defects in manufactured products.

### 5. Retail Shelf Monitoring
Counts and tracks product availability.

## Conclusion
YOLOv8 enables efficient real-time object detection for multiple real-world applications using image-based processing.
