# PSO-Based Computer Vision Case Studies

## Overview
This project demonstrates the use of Particle Swarm Optimization (PSO) for template-based object localization in different computer vision applications.

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib

---

# Case Studies

## 1. Satellite Object Detection
PSO is used to locate vehicles or structures in satellite imagery using template matching and texture similarity.

### Applications
- Disaster response
- Military surveillance
- Urban planning

---

## 2. MRI Tumor Detection
PSO searches MRI scans for regions matching a tumor template using grayscale similarity.

### Applications
- Medical diagnosis
- Radiology assistance
- AI-aided healthcare

---

## 3. Industrial Conveyor Belt Inspection
PSO verifies whether industrial components are correctly placed on conveyor belts.

### Applications
- Manufacturing QA
- Automated inspection
- Assembly line monitoring

---

## 4. Wildlife Recognition
PSO identifies endangered animals in forest surveillance images using body or face templates.

### Applications
- Wildlife monitoring
- Conservation systems
- Animal tracking

---

## 5. Logo Detection in Videos
PSO detects logos in advertisement videos by matching logo templates in video frames.

### Applications
- Media analytics
- Sponsorship analysis
- Advertisement verification

---

# Features
- Template matching
- Bounding box localization
- Frame skipping for faster video processing
- Real-time PSO search optimization
