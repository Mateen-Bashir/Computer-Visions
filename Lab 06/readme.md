\# Computer Vision Lab Task

\## Edge Detection Algorithms and Applications



This repository contains implementations of major \*\*edge detection techniques\*\* used in Computer Vision.



The project was developed as part of a \*\*Computer Vision Lab\*\* to understand how edge detection works and how it is applied in real-world scenarios.



\## Objectives

\- Implement Sobel Edge Detection

\- Implement Prewitt Edge Detection

\- Implement Canny Edge Detection

\- Apply edge detection to practical case studies



\## Algorithms Implemented



\### Sobel Operator

The Sobel operator calculates image gradients in two directions:

\- X direction

\- Y direction



The magnitude of gradients helps in detecting edges.



\### Prewitt Operator

Prewitt uses convolution kernels to approximate the gradient of the image intensity.



\### Canny Edge Detector

Canny is considered one of the most effective edge detection algorithms.



Advantages:

\- Noise reduction

\- Accurate edge detection

\- Thin edges

\- Reduced false detections
