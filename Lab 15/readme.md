# 🧠 Handwritten Digit Recognition using Deep Learning

A multi-case study AI project based on MNIST dataset using TensorFlow/Keras.

---

## 🚀 Features
- CNN-based digit classification
- Fully connected neural networks
- Feature extraction for fraud detection
- TensorFlow Lite deployment
- Clustering-based handwriting analysis

---

## 📂 Case Studies

### 🏦 Banking Cheque Processing
Automated digit recognition for cheque amount and account numbers.

### 📄 Exam Evaluation System
Predicts handwritten student answers for auto-grading.

### 🌍 Multilingual Digit Recognition
CNN model adaptable for multiple numeral systems.

### 📱 Edge Device Deployment
Lightweight model converted to TensorFlow Lite.

### 🔐 Fraud Detection System
Detects inconsistencies in handwriting using clustering.

---

## 📊 Dataset
MNIST Handwritten Digits Dataset
