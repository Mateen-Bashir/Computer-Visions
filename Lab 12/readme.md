# Machine Learning Case Studies

This project contains implementations of different machine learning and data preprocessing techniques using Python and Scikit-learn.

## Included Case Studies

### 1. Patient Health Risk Prediction
Technique Used:
- Auto Scaling (Normalization)

Description:
Patient health data such as blood pressure, cholesterol, heart rate, and glucose levels were normalized using StandardScaler before applying Logistic Regression.

---

### 2. Seasonal Crop Yield Forecasting
Technique Used:
- Auto Correlation

Description:
Historical crop yield data was analyzed using auto-correlation to identify seasonal patterns.

---

### 3. Creditworthiness Assessment
Technique Used:
- Feature Weighting

Description:
Logistic Regression coefficients were used to determine the importance of features like income and credit history.

---

### 4. Anomaly Detection in Industrial Machines
Techniques Used:
- Auto Scaling
- Auto Correlation

Description:
Sensor data from industrial machines was scaled and analyzed using auto-correlation to detect repeating anomalies.

---

### 5. Intrusion Detection in Network Security
Techniques Used:
- Auto Scaling
- Feature Weighting

Description:
Random Forest feature importance and scaling were used to identify important cybersecurity intrusion indicators.

---
